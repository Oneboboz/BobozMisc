## 交付要求

每完成一个模块，都提供：
1. 源代码
2. README
3. PC 单元测试
4. ESP32-S3 实机结果
5. Flash/RAM 占用
6. 已知问题
7. 至少 20 条测试句

不要做成“逐单词查词典 + 中文释义拼接”。

不要把 ASR、NLP、翻译、UI 全部写在一个 `main.cpp`。
